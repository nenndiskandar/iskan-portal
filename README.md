# iskan-portal - Dashboard Status

Dashboard monitoring real-time untuk mengawasi kesehatan layanan.

## Tech Stack
- **Port**: 3005
- **Frontend**: Express static (minimal UI)
- **Backend**: Node.js/Express
- **Framework**: WebJS (zero-dep HTTP server)

## Quick Start

```bash
npm install
npm start
# Server runs on http://localhost:3005
```

## Features
- Real-time service health check
- Minimal dark-mode UI
- Zero external dependencies (Express-based)
- No build tools (plain JS)
